🔐 PGP Anahtarları (uçtan uca şifreleme)

Bu anahtarlar size aittir. Public key'i karşı tarafla paylaşabilir, private key ile gelen şifreli mailleri açabilirsiniz.

Karşı tarafın public key'ini buraya ekleyin - sonra ona şifreli mail gönderebilirsiniz.

🔐 PGP Nedir?

PGP (Pretty Good Privacy), e-posta içeriğini sadece alıcının okuyabileceği şekilde şifreler. Sunucuya kayıtlı şifreli mailler bile siz private key ile açana kadar okunamaz.

Nasıl Kullanılır?

  1. Yeni Anahtar Üret - Email + güçlü bir passphrase (en az 8 karakter)
  2. Public Key'i Paylaş - Karşı tarafa export edip gönderin (e-posta veya başka kanal)
  3. Karşı Tarafın Public Key'ini İçe Aktar - Onun anahtarını size verdiğinde "Public Key İçe Aktar" ile ekleyin
  4. Şifreli Mail Gönder - Compose'da "🔐 Şifrele" toggle'ını açın - sadece o kişi açabilir
  5. Şifreli Mail Aç - Gelen şifreli maillerde "🔓 Aç" butonuna basın - passphrase istenir

⚠ Önemli

  • Passphrase'i unutmayın! Unutursanız private key'iniz işe yaramaz hale gelir, geri alınamaz.
  • Public key herkesle paylaşılabilir. Private key ASLA paylaşılmaz.
  • Konu satırı şifrelenmez - sadece mesaj gövdesi şifrelenir.
  • Karşı tarafın da PGP destekli bir mail uygulaması kullanması gerekir.

🗝 Yeni PGP Anahtarı Üret

ECC Curve25519 anahtar çifti üretilecek (modern, hızlı, güvenli).

⚠ Bu passphrase'i unutmayın - geri alınamaz!
⏳ Anahtar üretiliyor... (birkaç saniye sürebilir)

📥 Public Key İçe Aktar

Karşı tarafın size verdiği -----BEGIN PGP PUBLIC KEY BLOCK----- ile başlayan tüm metni yapıştırın.

📤 Public Key Paylaş

Bu metni karşı tarafa gönderin. Onlar da içe aktarsın.

🔓 Şifreli Mesajı Aç

Bu mesaj sizin için şifrelenmiş. Açmak için private key passphrase'ini girin.

🦠 VirusTotal Tarama

        

          Ücretsiz VirusTotal API anahtarı ekleyerek ek dosyalarınız 70+ antivirüs motoruyla taranabilir. Dosyalar yüklenmez, sadece SHA-256 hash bazlı sorgu yapılır (gizliliğiniz korunur). Anahtar almak için: virustotal.com/gui/join-us
